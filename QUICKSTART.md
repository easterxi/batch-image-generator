# 5-minute checklist

1. Upload this project to a new GitHub repository.
2. Put your reference image in Google Drive at `MyDrive/comfy-batch/reference.png`.
3. Open `notebooks/colab_controlnet_batch.ipynb` in Colab.
4. Choose a GPU runtime.
5. Set your `GITHUB_REPO`.
6. Set checkpoint filename + direct URL.
7. Set Canny ControlNet filename + direct URL.
8. Set `COUNT = 10`.
9. Run all notebook cells.
10. Check `MyDrive/comfy-batch/outputs`.

After testing, change `COUNT` to `100`, `1000`, or `10000`. Re-running resumes from existing output files.
